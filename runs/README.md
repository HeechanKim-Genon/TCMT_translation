> (`mass` 가 종괴인지 질량인지는 문서마다 다르다).

## 최종 채점 — LLM 정렬 (`c_para_aligned.*`)

`term_hit` 은 **번역문 어딘가에 표준 한글명이 있는가**만 본다. 그 용어의 번역으로 쓰였는지는
보지 않는다. 위치를 모르므로 이런 오채점이 난다.

```
문단 P001 의 채점 대상:  case-mix  (정답 = 질병구성)
  · case-mix 에게 준 오답        →  인두편도 생검
  · 같은 문단 renal 에게 준 오답  →  질병구성      ← case-mix 의 정답!

모델은 renal 을 "질병구성"으로 충실히 옮겼다 (오답을 잘 따랐다).
그런데 채점기는 그 "질병구성"을 보고 case-mix 가 맞혔다고 센다.
```

`score_align.py` 가 이를 고친다. **LLM은 정렬만, 채점은 코드가 한다.**

```
1. LLM에게  영어 문단 + 한국어 번역문 + 대상 영어 용어  를 준다
2. 번역문에서 그 용어에 해당하는 부분만 그대로 잘라내게 한다 (번역 금지)
3. 잘라낸 span 이 실제로 번역문의 부분문자열인지 코드로 검증
4. span 을 정답 집합과 대조해 채점
```

채점자는 **Qwen3.5-397B** — 번역한 GLM 이 자기 답을 채점하면 자기 선호가 낀다.
LLM 에게 정답을 보여주지 않는다. 보여주면 "정답이 있냐"는 유도 질문이 된다.
부분문자열 검증이 응답 교차 탐지도 겸한다.

`random` 모드는 질문을 두 번 한다. 채점용(의미)으로는 추종률을 잴 수 없기 때문이다 —
모델이 그 자리에 엉뚱한 용어를 써 넣으면 "이 용어를 옮긴 부분"이 없어 `NONE` 이 돌아온다.
그래서 **의미를 묻지 않고 위치만 묻는** 프롬프트(`SYS_POS`)를 따로 쓴다.

### 표기 관례 처리

정답으로 인정한다 — 공백(`손목굴 증후군`), 조사(`털증을`), 끝 하이픈(`불수의-`),
괄호 한자(`합곡(合谷)`), 생략 가능 접미(`해마경화(증)`). 조사와 괄호는 **파괴적으로
떼지 않고 후보로만 추가**한다. 그냥 떼면 `배양` 처럼 끝 글자가 조사와 겹치는 용어가 망가진다.

반대로 표준명보다 **짧게** 잘린 것은 오답이다. `주혈흡충` → `혈흡충`,
`신경정신과학` → `신경정신과` 는 다른 뜻이 된다.

## 결과를 해석하기 전에 볼 것 — `crossing`

각 `*_summary.json` 에 `crossing` 필드가 있다. 서빙이 다른 요청의 응답을 돌려주는
현상(응답 교차)의 탐지·복구·미해결 건수다. 자세한 설명은 저장소 루트 README 참고.

이번 실행 실측:

| 규모 · 단계 | 탐지 | 복구 | 미해결 |
|---|---|---|---|
| 1000 · 단어 (3,124호출) | 10 | 7 | 3 |
| 1000 · 문장 (3,002호출) | 2 | 2 | 0 |
| 1000 · 문단 (1,369호출) | 102 | 11 | **91** |
| 100 · 문장 (301호출) | 1 | 1 | 0 |
| 100 · 단어 / 문단 | 0 | 0 | 0 |

문단의 91건은 **탐지기 오탐**이다. 89건이 `random` 모드인데, 거기서는 모델이 오답을
따라가므로 자기 정답이 안 나오는 게 정상이라 판정이 헐렁하게 걸렸다. 의심 문단과 정상

의심 0건이다.** 판정 기준은 이 실행 이후 수정했으므로 다시 돌리면 이 숫자는 줄어든다.

## 알려진 한계

- **문단 결과에 `raw` 필드가 없다.** 문단 번역은 응답 전체가 번역문이라 파싱할 게 없어서
  `ko` 에 정규화만 적용해 넣었다. 실질적으로 원문과 같지만 엄격히는 원문 그대로가 아니다.
- **`random` 의 오답 풀 결함은 코드로 고치지 않았다.** 오답을 채점 대상 용어들의 한글명
  풀에서 뽑기 때문에, 어떤 용어의 오답으로 같은 문단 다른 대상 용어의 정답이 배정되는
  경우가 있다. `c_para_aligned.*` 의 정렬 채점이 이를 **우회**하지만(위치를 보므로),
  근본 수정은 오답 풀에서 "같은 문단의 채점 대상 용어 한글명"을 빼는 것이다.
  `c_para_random.json` 의 `term_hit` 과 `followed_decoy` 는 이 결함이 그대로 남아 있다.
- 문단은 사전 용어로 만든 **합성 데이터**다. 실제 진단서·소견서가 아니다.
