# data/

사전 CSV 를 여기에 둔다. 저작권 문제로 저장소에는 포함하지 않는다.

| 파일 | 설명 |
|---|---|
| `dictionary.csv` | 최종 번역사전 (약 7.7만 행 / 고유 영문명 5.6만) |
| `dictionary_sample2000.csv` | 빠른 점검용 표본 (2,806행 / 영문명 2,000) |

## 12컬럼 스펙

```
용어코드, 개념코드, 영문명, 한글명, KCD, ICD9CM, LOINC, EDI, CCC, ICNP, CDT, SNOMED CT
```

- `KCD` 는 `C96|C96.00` 처럼 다중값일 수 있다 (`|` `;` `,` 로 분리)
- 같은 `개념코드` 를 공유하는 `한글명` 은 전부 정답으로 인정된다 (동의어)
- 코드 컬럼은 캐리어 문장 유형 판정에 쓴다 — KCD/ICD9CM→진단, EDI/CDT→처치, LOINC→검사

경로는 `TCMT_DICT` / `TCMT_DICT_SAMPLE` 환경변수로 바꿀 수 있다.
